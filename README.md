# Website Lab
**Contributors:** [ericrothdotorg](https://github.com/ericrothdotorg)

The code behind [ericroth.org](https://ericroth.org/), a personal WordPress site: One Human | Many Worlds. Shared as it is: Use it, take it apart, borrow what you like.

**Tags:** wordpress, block-theme, eric-theme, eric-snippets, eric-slider, website-lab

---

**Eric Theme:** [eric-theme](https://github.com/ericrothdotorg/eric-theme)

The block theme (FSE): Templates, template parts, theme.json and plain CSS. No build step, no webfonts. Its README explains how theme, snippets, Eric Slider and the Display Posts plugin fit together. Installable zip: [Releases](https://github.com/ericrothdotorg/eric-theme/releases).

**Eric Snippets:** [eric-snippets](https://github.com/ericrothdotorg/eric-snippets)

Everything dynamic on the site: Shortcodes, header bar, custom post types, quotes, stats and more.

**Eric Slider:** [eric-slider](https://github.com/ericrothdotorg/eric-slider)

A lightweight, zero-dependency vanilla JavaScript slider / carousel. No jQuery, no bloat - just clean, accessible HTML output with smallest footprint possible.
