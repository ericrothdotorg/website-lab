# Website Lab

**Contributors:** [ericrothdotorg](https://github.com/ericrothdotorg)

The code behind [ericroth.org](https://ericroth.org/), a personal WordPress site: One Human | Many Worlds. Shared as it is: Use it, take it apart, borrow what you like.

**Tags:** website-lab, wordpress, block-theme, eric-theme, eric-snippets, eric-slider

---

**What makes it genuinely stand out**

Most WordPress sites are built from a page builder, a premium theme and a long list of plugins. This one is built from three small, readable parts: A block theme for the look, a set of code snippets for everything dynamic, and a vanilla JavaScript slider. No page builder, no build step, no webfonts, no framework. Every line exists because a real page on a live site needed it, so nothing here is demo code.

**Who would actually reach for it**

WordPress developers who want to see how a complete, real site fits together, not just one theme or one plugin in isolation. It's not a product to install and forget: It's one person's site, shared as a working reference to learn from, borrow from or take apart.

## Principles

- **No build step:** Upload or drop in files and they run.
- **No page builder, no framework:** Blocks, PHP and plain CSS and JavaScript.
- **Load only what's needed:** Per-block CSS and conditional snippets keep pages light.
- **Readable over clever:** Commented code with stated conventions.
- **Real, not demo:** Built for one live site, so expect to adapt names, IDs and settings.
